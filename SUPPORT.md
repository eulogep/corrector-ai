# Support

## Utiliser Corrector AI

Commencez par le [README](README.md) pour l’installation locale et par le [guide de déploiement](docs/DEPLOYMENT.md) pour Docker, Redis, Prometheus, Grafana, Alertmanager et Locust. Consultez `GET /docs` sur une instance locale pour le contrat de chaque endpoint.

## Poser une question ou proposer une idée

Utilisez une issue GitHub avec le libellé `question` ou `documentation` pour une question liée au projet. Décrivez le contexte, l’objectif recherché, les étapes déjà essayées et les logs expurgés de toute donnée personnelle ou secret. Les demandes d’évolution structurées doivent utiliser le modèle de fonctionnalité.

## Signaler un défaut

Utilisez le modèle de bug et fournissez une reproduction minimale, le comportement observé, le comportement attendu, la version ou le commit et l’environnement. N’incluez aucune copie d’élève réelle.

## Sécurité

Les signalements de vulnérabilités suivent la procédure de [SECURITY.md](SECURITY.md), et ne doivent pas être publiés dans une issue ordinaire.
