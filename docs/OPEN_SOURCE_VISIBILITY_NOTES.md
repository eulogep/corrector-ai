# Notes de visibilité open source

Les recommandations officielles GitHub consultées confirment deux leviers applicables à Corrector AI.

Les fichiers de santé communautaire tels que `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`, `SUPPORT.md`, les modèles d’issues et de pull requests standardisent les contributions et rendent les attentes transparentes. GitHub les considère dans son profil de communauté d’un dépôt public.

Les topics classent publiquement un dépôt par usage, domaine et technologie. Ils permettent aux personnes qui explorent ces sujets de découvrir des dépôts et d’y contribuer. GitHub autorise jusqu’à vingt topics, limités aux minuscules, chiffres et traits d’union.

Sources consultées le 12 août 2026 :

1. https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file
2. https://docs.github.com/fr/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/classifying-your-repository-with-topics
